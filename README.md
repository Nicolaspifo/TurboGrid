# Turbo Grid · Página del juego

Sitio de presentación de **Turbo Grid: Carrera de Combustible** publicado con GitHub Pages.
El código del juego (Unity) está en las otras ramas del repositorio.

- `index.html` y `assets/estilos.css`: la página.
- `assets/img/`: imágenes tomadas del arte del juego (optimizadas para web).

Para actualizarla: edita estos archivos en la rama `gh-pages` y haz push; GitHub la publica sola en 1–2 minutos.
